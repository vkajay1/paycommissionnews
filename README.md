# PayWise Pro

Project Overview

Create a modern web application called '8th CPC Calculater'.

This is an advanced salary, pension, arrear, and pay-matrix calculator platform for Indian Central Government employees and pensioners.

DO NOT copy the design of 8cpccalculator.com.

Build a premium SaaS-style interface inspired by modern fintech products like Zerodha, Groww, CRED, and Stripe.
