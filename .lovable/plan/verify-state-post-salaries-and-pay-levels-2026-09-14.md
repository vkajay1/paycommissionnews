# Verify state post salaries and pay levels

## Scope
Audit every cadre currently shown across all 36 state and union-territory salary pages.

## Approach
1. Verify each post against an official recruitment notice, pay rules, commission notification, or department source where available.
2. Use reputable exam-preparation sources such as Adda247 or Physics Wallah only when the official source is unavailable or unclear.
3. Replace incorrect central-pay placeholders with the applicable state pay level, pay scale, and entry basic pay.
4. Mark genuinely variable or designation-dependent cases clearly instead of presenting an unsupported exact level.
5. Add source links and a “verified/source” presentation to each cadre table so readers can check the evidence.
6. Update projections and long-tail answers automatically from the corrected current basic pay.
7. Verify representative state pages on desktop and mobile, and check the site build.

## Technical details
- Extend state cadre data with source label, source URL, and optional pay-scale wording.
- Preserve one source-backed canonical value per listed post; avoid treating similarly named posts in different states as equivalent.
- Keep all 8th CPC figures labelled as estimates because no final state adoption orders exist yet.
