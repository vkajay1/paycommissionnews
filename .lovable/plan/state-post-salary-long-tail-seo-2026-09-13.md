# State Post Salary Long-Tail SEO

## Scope

1. Add a dedicated section to every dynamic state and Union Territory salary page titled around “Post salary after 8th Pay Commission in [State]”.
2. Generate one natural long-tail heading and short answer for every cadre already listed for that state, including the projected basic salary at the existing 2.57x and 2.86x scenarios.
3. Include those post-specific phrases in each page’s search metadata and add matching FAQ structured data so search engines can understand each question and answer.
4. Improve generic-state coverage by replacing the shared generic cadre list with state-named versions in the rendered wording, while keeping existing salary figures and disclaimers unchanged.
5. Verify representative pages on desktop/mobile, metadata output, structured data, and the site build.

## Technical details

- Reuse `STATE_PAGES`, each state’s `cadres`, and the existing `levelProjection` calculation.
- Generate visible, useful answers rather than standalone keyword lists to avoid keyword stuffing.
- Keep all projections clearly marked as estimates; no new factual claims or notified fitment-factor claims will be introduced.
